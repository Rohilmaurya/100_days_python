# Day 13 - Debugging

Today I focused on debugging Python programs and understanding how to find and fix errors.

## What I Practiced

- Reading error messages
- Using the debugger
- Finding syntax and logical errors
- Using print statements to track program flow
- Identifying incorrect variable values
- Testing code after making fixes

## Key Takeaway

Debugging isn't just about fixing errors. It's about understanding why the code behaves differently from what I expected.
